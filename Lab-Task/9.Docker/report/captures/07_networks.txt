# 2. the api has no published port on the host
$ docker compose port api 8000
:0          (empty: no host mapping exists)

# 3. the api cannot reach the internet (internal network)
$ docker compose exec api python -c "import urllib.request; urllib.request.urlopen(\"https://pypi.org\", timeout=5)"
urllib.error.URLError: <urlopen error [Errno -3] Temporary failure in name resolution>
