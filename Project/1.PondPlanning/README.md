# AI-based Village Pond Planning System

[![CI](https://github.com/Rahul5977/AI-BasedPondAnalysis/actions/workflows/ci.yml/badge.svg)](https://github.com/Rahul5977/AI-BasedPondAnalysis/actions/workflows/ci.yml)

Terrain, catchment and runoff analysis to help village administrators site
farm ponds from geospatial data.

> **Stub.** The full installation guide — prerequisites, verification checklist
> and troubleshooting table — is a graded deliverable written in P7. Until then:

```bash
make install   # uv venv + dependencies (Python 3.12)
make up        # start the stack and migrate -> http://localhost:8000/docs
make check     # ruff + mypy + pytest, exactly what CI runs
make help      # every target
```
