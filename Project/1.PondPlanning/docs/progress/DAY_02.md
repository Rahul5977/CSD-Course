## What worked

P0 chunk 2 landed. **G0 is closed and 11 marks are secured.**

- **The full API contract is live** — 35 operations across 33 paths, every one
  returning a realistic fixture. This is the parallelism unlock: the frontend can
  now be built against the final payloads without waiting for P3 or P4.
- **`app/domain/units.py`** — a `Quantity` value object carrying value, unit,
  uncertainty band and derivation method. The "units and uncertainty on every
  number" rule is now enforced by the type system rather than by discipline;
  there is no way to construct a result without saying what it means.
- **`app/domain/errors.py` + RFC 9457 problem details.** One error shape for the
  whole API, with stable machine-readable codes. `GET /api/v1/meta/errors`
  generates the catalogue from the same table the handlers use, so
  `docs/api/errors.md` cannot drift from behaviour.
- **17 fixture payloads**, generated by one script so they are internally
  consistent — the runoff really is catchment area × dependable rainfall ×
  runoff coefficient, and the gross storage really is the prismoidal integral of
  the EAV curve. Inconsistent fixtures teach the frontend wrong relationships
  and hide unit bugs.
- **Honest scaffolding.** Every fixture response sets `X-Fixture-Data: true` and
  carries a `fixture_data` warning at `critical` severity, and
  `GET /api/v1/meta/implementation-status` reports `engines_implemented: []`. A
  test asserts all three, so P0 cannot quietly look more finished than it is.
- **ADRs 0005–0012** — FastAPI over Flask, PostGIS over MongoDB, DEM rasters over
  point-elevation APIs, async jobs, D8, three runoff methods, the contour KML
  adapter, and ownership-class/upload hardening. Three of those are rows of the
  stack reconciliation table the report needs.
- **Repository restructured** to a conventional layout: `Docs/` → `docs/`,
  `Plan/` → `docs/assignment/`, the two trackers moved under `docs/`. Root now
  holds only what convention expects there.
- **Evidence captured:** `docs/api/openapi.json`, two Swagger screenshots, the

## What broke

- **The `Docs/` → `docs/` rename needed two `git mv` steps.** macOS is
  case-insensitive, so the single-step rename is a no-op that git records as
  nothing. Renamed via `docs_tmp` in between.
- **`ruff` sorted `app` before `fastapi`.** Fixed in DAY_01 with
  `known-first-party`; worth recording because the symptom (import order
  churning on every format) looks like a formatter bug rather than a config one.
- **Two `mypy --strict` findings in the schemas** — a bare `dict` annotation and
  a `default_factory` whose `list[str]` did not match the `Literal` element type.
  Both were real: the second would have let an invalid runoff method through the
  default path. Fixed with `get_args(RunoffMethod)`.
- **Starlette deprecation:** `HTTP_422_UNPROCESSABLE_ENTITY` → `..._CONTENT`.

## Decisions made

Each has an ADR; the non-obvious ones are mirrored into the `docs/PROGRESS.md`
decision log.

- **Units and uncertainty enforced by a domain type,** not by convention. A rule
  written in a document decays; a constructor that demands a unit does not.
- **RFC 9457 problem details with stable codes,** generated into a catalogue
  endpoint. Half the API-documentation mark is the error catalogue, and
  generating it means it cannot go stale.
- **Fixtures must announce themselves.** Header, warning, and a status endpoint.
  A stub indistinguishable from a real result is a trap for the frontend and
  misleading to an evaluator.
- **The fixture village is deliberately not the sample KML's area of interest.**
  Nothing in `app/providers/fixture_data/` may become a source of truth for the
  provided map, because the assignment grades derivation from the input.
- **`/analysis/results/*` routes exist** so the OpenAPI document carries the full
  result payloads, not only the `202` envelopes. Without them the frontend would
  have no schema to build against — which would defeat the point of the phase.
